## Why is This Prediction Reasonable?

Detailed mechanism-of-action data for ziprasidone are not available in the data compiled for this report. Ziprasidone belongs to the atypical antipsychotics, which block serotonin 5-HT2A and dopamine D2 receptors. Dopamine and serotonin signalling are both thought to be involved in repetitive, compulsive-type behaviours, so a mechanistic link to trichotillomania is plausible.

The use of antipsychotics as add-on treatment has been discussed for trichotillomania in general. However, the data compiled for this report contain no ziprasidone-specific evidence for this condition. The prediction is therefore a hypothesis generated by the model and has not been tested.
