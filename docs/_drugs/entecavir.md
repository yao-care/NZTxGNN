## Entecavir: Chronic hepatitis C virus infection
{: .text-alpha }

## One-Sentence Summary

Entecavir is an oral guanosine nucleoside analogue that inhibits the hepatitis B virus polymerase.
The TxGNN model predicts it may be relevant to **chronic hepatitis C virus infection**, but the supporting studies test entecavir only for preventing hepatitis B reactivation during hepatitis C treatment, not for treating hepatitis C. The evidence level is therefore **L5**: model prediction only.

## Why is This Prediction Reasonable?

Detailed mechanism of action data is not available in the compiled data. From general pharmacology, entecavir is a guanosine nucleoside analogue that blocks the hepatitis B virus DNA polymerase.

Hepatitis C virus is an RNA virus that replicates through a different enzyme, the NS5B RNA-dependent RNA polymerase. Entecavir has no known direct activity against it, so there is no direct mechanistic basis for treating hepatitis C with entecavir.

The only plausible link is indirect. In patients infected with both viruses, hepatitis B can reactivate when hepatitis C is cleared with direct-acting antivirals. Entecavir suppresses hepatitis B replication in that setting. The signal behind the prediction therefore concerns managing co-infection, not treating hepatitis C itself. Because of this, the evidence level is set at L5.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The high model score is not backed by any study of entecavir as a hepatitis C treatment. The trials and the randomized study address only prevention of hepatitis B reactivation during hepatitis C therapy, and entecavir has no known direct activity against hepatitis C virus.

**To proceed, the following is needed:**
- Mechanistic or in vitro evidence of any anti-hepatitis C activity, since none is currently known
- Mechanism of action data for the compiled record
- Package insert warnings and contraindications from Medsafe for a safety review
